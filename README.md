# Abuzar Gifary — Personal Portfolio

A minimal, responsive personal portfolio website for **Abuzar Gifary** ([@abzgif](https://github.com/abzgif)), Full-Stack Web Developer and Founder of **[ByteGif](https://bytegif.com)**.

## Highlights
- **Minimal Editorial Design:** Built with Tailwind CSS, `Inter`, and `JetBrains Mono` typography with persistent light and dark mode support.
- **Featured ByteGif Apps:** Compact showcase of Android and macOS applications ([OpenCast](https://play.google.com/store/apps/details?id=com.bytegif.opencast), [GlassBeat](https://play.google.com/store/apps/details?id=com.bytegif.glassbeat), [Audio Tag Editor](https://play.google.com/store/apps/details?id=com.bytegif.audiotageditor), [Image Resizer](https://play.google.com/store/apps/details?id=com.bytegif.imageresizer), [Real Mirror](https://github.com/abzgif/Android-Real-Mirror), SendChat, CleanMac, and Mac Network Monitor) linking directly to [Google Play](https://play.google.com/store/apps/dev?id=5212652438690411522&hl=en) and [GitHub](https://github.com/abzgif).
- **Websites & Web Applications:** Showcases live web projects including [Care Life Bangladesh](https://carelife-bangladesh.web.app) and [JBDC Webapp](https://jbdc-app.web.app).
- **Direct Contact:** Integrated Web3Forms contact form and direct social links.
